# New Build — تشغيل السحب الآلي

## التشغيل المجاني
ارفع **كل محتويات هذا المجلد** إلى جذر مستودع GitHub عام، بما فيها المجلد المخفي `.github/workflows/` (لا ترفع ملف ZIP كعنصر واحد). في Settings → Pages اختر Deploy from a branch → main / root. ثم Actions → New Build automatic tenders and public leads → Run workflow. يجب أن يسمح المستودع لـ GitHub Actions بالكتابة: Settings → Actions → General → Workflow permissions → Read and write permissions.

الجدولة: 09:00 و13:00 UTC = 12:00 و16:00 بتوقيت دمشق. GitHub قد يؤخر الجداول، ويوقف الجداول في المستودعات العامة غير النشطة بعد 60 يوماً. لا يعمل التحديث تلقائياً بمجرد فتح الملف المحلي.

## قنوات الجمع
- `discovery_sources.json`: صفحة Telegram العامة للمناقصات في سوريا ودول الجوار مفعلّة، وستحاول القراءة على GitHub. قناة «خطوة» و«مناقصتك» غير مفعّلتين حتى إدراج معرفيهما الصحيحين.
- `discover.py`: يقرأ المنشورات العامة ويستخرج **إعلانات مرشحة غير موثقة** إلى `candidates.json`. هذا ليس ربط Telegram API رسمياً؛ نجاح الجلب يعتمد على إتاحة صفحات القناة العامة والبنية الحالية للصفحة.
- `update.py`: يجمع السجلات الموثقة يدوياً في `manual_tenders.csv` وملفات HTTPS JSON المفعلة في `sources.json` إلى `tenders.json`. لا يستورد المرشحات تلقائياً باعتبارها مناقصات.
- Facebook غير موصول؛ يتطلب واجهة أو وصولاً معتمداً. UNGM API يتطلب تصريح وصول، ولا يستخدم تلقائياً. ReliefWeb يتطلب appname معتمداً ولا يعد فهرساً شاملاً للمناقصات.
- قد تبقى قاعدة المناقصات المؤكدة فارغة حتى توفر البيانات من مصدر أصلي أو مراجعة إعلان.

## التحقق
بعد Run workflow افتح ملف `discovery_status.json` لمعرفة نتيجة اتصال Telegram وعدد الرسائل المقروءة والأخطاء. `last_check.json` يبين نتائج مسار المناقصات الموثقة. لا يعني وجود 281 جهة أن هناك 281 مصدر استخراج موصول.

## أمان
لا يحتوي الملف على EXE أو PowerShell أو تعليمات لتعطيل مضاد الفيروسات، لكن افحص ملف ZIP باستخدام Windows Defender قبل الاستخدام. لا تضع رموز وصول أو كلمات مرور في المستودع العام.
